## 💡 6 FEATURES EXPLAINED (30-Second Each)

### Feature 1: Outlier Detection
```
Automatically finds weird/anomalous rows
IQR method: detects values outside 1.5×IQR
Why? Bad data makes bad predictions
Use: Click checkbox to exclude during training
```

### Feature 2: Equations
```
Shows math formulas for predictions
Format: Output = a + b×Input1 + c×Input2 + ...
Why? Verify in Excel, document in reports
Use: Copy-paste formulas into spreadsheets
```

### Feature 3: Confidence Scores
```
Converts distance to 0-100% trust rating
90%+ = Trust | 70-89% = Use with care | <60% = Validate
Why? Know when predictions are reliable
Use: Green bar = use, Red bar = question
```

### Feature 4: Categories
```
Auto-detects text fields and uses them
Region, Type, Status, etc. become inputs
Why? Qualitative data matters for predictions
Use: Dropdown menus for text selections
```

### Feature 5: Similar Records
```
Finds 5 most similar historical cases
Why? Compare your prediction to actual outcomes
Use: Validate predictions match reality
```

### Feature 6: Multi-File Foundation
```
Architecture ready to combine data sources
Planned for V4: Merge multiple CSVs
Why? More data = better predictions
```

```
✓ Hard refresh: Ctrl+Shift+R

✓ Check: Port 5173 accessible

### CSV Won't Upload
```
✓ Check: File is .csv format
✓ Check: Headers in row 1
✓ Check: At least 5 data rows
✓ Check: No special characters in column names
✓ Solution: Save Excel as CSV and try again
```

### Models Won't Train
```
✓ Check: Selected input columns (X)
✓ Check: Selected output column (Y)
✓ Check: Selected at least one model
