## ✨ 6 FEATURES AT A GLANCE

| # | Feature | What It Does | Why It Matters |
|---|---------|------|-----|
| 1 | **Outlier Detection** | Finds anomalous rows automatically using IQR method | Clean data = accurate predictions |
| 2 | **Prediction Equations** | Shows mathematical formulas for Linear & Ridge models | Manual verification, Excel use, documentation |
| 3 | **Confidence Scores** | Converts model distance to 0-100% trust rating | Immediate understanding of prediction reliability |
| 4 | **Categorical Encoding** | Auto-detects text fields and uses them in predictions | Text/category data has predictive value |
| 5 | **Similar Records** | Finds 5 most similar historical records for validation | Confirm predictions against real historical data |
| 6 | **Multi-File Foundation** | Architecture ready for combining multiple data sources | Future enhancement for enriched features |
